### 2.3 어댑터 여유

- 5V 4A 어댑터 대비: 순차 순간 최대 0.96 A → **약 4.2배**, 동시 순간 1.77 A → **약 2.3배**. 최악 2.97 A도 정격 이내.
- 연속 전력: 최대 약 6.9 W (어댑터 20 W의 약 35%) → 발열 문제 없음.

### 2.5 전압 강하와 ESP32 레귤레이터 여유

- 어댑터 케이블 + SW1 접점 + 퓨즈 + 배선 저항 합 ≈ 0.15~0.2 Ω (추정) → 1.37 A에서 약 0.2~0.3 V 강하 → ESP32 5V 핀 약 4.7~4.9 V.
- DevKitC의 3.3V LDO는 입력이 약 4.3~4.4 V 이상이면 정상 출력(드롭아웃 약 1 V급 가정) → 여유 있음. 순차 구동에서는 강하가 더 작음.

## 3. 3.3V 로직으로 옵토 릴레이를 구동하는 근거

- 보드 구조(사진 확인): 입력 헤더 `VCC IN4 IN3 IN2 IN1 GND`(치수도 방향 기준 위→아래), 2핀 점퍼 `JD-VCC | VCC`, 별도 코일 GND 핀 없음(코일 전류는 입력 헤더 GND로 귀환).
- 점퍼 헤더가 2핀뿐이라 **점퍼 캡을 끼우면 두 핀이 모두 덮여** JD-VCC 핀에 듀폰 소켓(⑨)을 같이 꽂을 수 없음 → B안에서는 +5V(⑨)를 **입력 헤더 VCC 핀(⑪을 뺀 자리)** 으로 넣고, 점퍼 캡을 통해 JD-VCC로 보냄. 이렇게 하면 VCC 핀을 ⑨가 차지하므로 3V3(⑪)을 실수로 다시 꽂을 자리도 없어짐.
- 입력 회로(추정, 일반적인 4채널 옵토 보드): `VCC → 1kΩ → 표시 LED(약 1.8 V) → 옵토 LED(약 1.15 V) → INx`.

| 방식 | IN = HIGH (OFF) | IN = LOW (ON) | 판단 |
|---|---|---|---|
| **A안 (SPEC)** 점퍼 제거, VCC = 3V3, JD-VCC = 5V | VCC − IN = 0 V → 전류 0 → **확실히 OFF** | (3.3 − 1.8 − 1.15) ÷ 1 kΩ ≈ **0.35 mA** (추정, 범위 0.3~0.7 mA) | 옵토 CTR이 낮으면 코일 트랜지스터가 덜 켜질 수 있음 → **시험 필수** |
| **B안** (USB·어댑터 분리 후) ⑪ 먼저 제거, ⑨(+5V)를 입력 헤더 VCC 핀으로 옮기고 점퍼 끼움 → VCC = JD-VCC = 5V | 5 − 3.3 = 1.7 V < LED 2개 문턱 약 2.6~3.0 V → **OFF** (추정) | (5 − 2.95) ÷ 1 kΩ ≈ **2.0~2.4 mA** → 확실히 ON | A안 실패 시 사용. **VCC를 3V3에 연결 금지** |

- ESP32 GPIO 부담: A안 싱크 약 0.35 mA, B안 약 2.4 mA → ESP32 권장 범위(수십 mA) 대비 매우 작음.
- B안에서 GPIO에 5V가 들어가는 경로: GPIO HIGH일 때 LED 직렬 회로에 걸리는 전압이 문턱 미만이라 전류가 거의 없고, 부팅 중(High-Z)에도 GPIO 보호 다이오드를 통해 흐를 만큼의 전압차가 생기지 않음(추정). 5V가 직접 GPIO에 닿는 배선은 없음.
- 부팅 순서: 펌웨어 `safeOutput()`이 `gpio_set_level(HIGH)`(출력 레지스터 선기록) → `pinMode(OUTPUT)` → `digitalWrite(HIGH)` 순서(SPEC §1; ESP32 코어 3.x는 `pinMode` 전에 부른 `digitalWrite`를 무시함, `config.h` RELAY_OFF_LEVEL=1)라 부팅 중 펌프가 튀지 않음. 리셋 직후 GPIO26/27/32/33은 입력 상태 → IN 핀에 전류 경로 없음 → OFF 유지.
- 핀 선택 검토: GPIO26·27·32·33·4·2·23은 모두 입출력 가능 GPIO. 입력 전용(34~39)·플래시(6~11) 미사용. GPIO2는 스트래핑 핀이지만 다운로드 모드 조건(LOW 또는 플로팅)을 LED+220Ω→GND가 방해하지 않음. GPIO32/33은 32 kHz 크리스털 핀이지만 DevKitC V4에는 크리스털이 없음.

## 4. 다이오드 정격 (D1~D4, 1N4007)

| 항목 | 요구 | 1N4007 | 판단 |
|---|---|---|---|
| 순방향 평균 전류 | 펌프 전류 0.2 A (차단 직후 수 ms) | 1 A | 5배 여유 |
| 순방향 서지 | 기동 전류 0.6 A 수준 | 30 A (8.3 ms) | 충분 |
| 역내압 | 평상시 5 V 역바이어스 | 1000 V | 충분 |
| 역회복 시간 | 릴레이 ON/OFF(초 단위) | 일반 정류용(수 µs) | 릴레이용으로 문제 없음. **PWM(MOSFET) 업그레이드 시 1N5819 쇼트키로 교체** |

- 방향: **띠(캐소드) = 펌프(+)**. 반대로 달면 릴레이 ON 때 5V–GND가 다이오드로 단락 → 5V 레일이 무너져 ESP32 재부팅(브라운아웃)·릴레이 해제, 또는 어댑터 보호 동작(꺼짐·재시작 반복). 4A 어댑터의 단락 전류(약 4~6 A, 추정)는 3A 퓨즈 정격의 1.5~2배라 **퓨즈는 끊어지지 않을 수 있고**, 1A 정격 다이오드가 약 4~5 W로 과열·소손될 수 있음. 특히 ESP32를 USB로 켠 디버깅 상태(⑧ 분리)에서는 릴레이가 계속 붙어 있어 단락이 이어질 수 있음 → "퓨즈 멀쩡 = 다이오드 정상"이 아님. 띠 방향을 눈으로 확인하고, 수축튜브가 변색·냄새 난 다이오드는 교체.
- 위치(SPEC §1): **① 펌프 리드선 이음부(뚜껑 위)** 또는 **② 연장선의 박스 쪽 끝** — **전기적으로 동일**(둘 다 펌프와 병렬).
  배선도(wiring.svg)는 ①로 그렸고, 조립 가이드 STEP3은 ②를 씁니다(젖지 않고, 펌프를 잇기 전에 멀티미터로 방향을 확인하기 쉬움).
  `parts_research.md` 3.5절·BOM P10의 "릴레이 쪽(띠 다리 → NO 단자, 반대 다리 → TB2)"도 ②와 같은 회로입니다.
- 역기전력 크기 예시(가정 L ≈ 1 mH, I = 0.2 A, 차단 1 µs): V ≈ 200 V, E ≈ 20 µJ → 다이오드가 약 0.8 V로 제한.

## 5. 커패시터 정격 (C1, 1000µF 16V 105℃)

- 내압: 16 V ÷ 5 V = 3.2배 여유(일반 권장 1.5~2배 이상) ✔
- 순간 강하 억제(추정): 펌프 기동 추가 전류 0.4 A가 0.5 ms 동안 C1에서만 공급된다고 가정 → ΔV = I·Δt ÷ C = 0.4 × 0.0005 ÷ 0.001 = **0.2 V**.
- 전원 투입 시 충전 돌입: 에너지 ½CV² = 12.5 mJ, 어댑터 출력 임피던스로 제한 → 퓨즈 I²t(3A 속단형 수 A²s급) 대비 무시 가능.
- 극성: 띠(−) → TB2, 긴 다리(+) → TB1. TB1 1번·TB2 8번이 맞닿게 두 커넥터를 나란히 고정해 다리를 바로 꽂음.
- (선택) ESP32 리셋이 생기면 P17 100µF를 ESP32 5V–GND 가까이에 추가.

## 8. 회로 구현 선택 (1~3, 5는 SPEC v2.1 §1에 반영됨)

1. **SW1 전원 스위치 + F1 3A 퓨즈**(BOM P13~P15). SPEC v2.1부터 정식 구성(회로도의 "권장" 표시 삭제).
2. **분배 커넥터 3개**: TB1 = +5V(8구 모두 사용), TB2 = GND(J1−, 펌프− ×4, C1−, 예비 2), **TB3 = 3V3**(ESP32 3V3 → 릴레이 VCC·부저 VCC). TB3에는 BOM의 PCT-418 예비분을 사용 → 남는 예비 1개.
3. **GND 별형(스타) 접지**: J1(−) 나사에 ⑤(→TB2, 펌프 귀환)와 ⑦(→ESP32 GND J3-1) 두 가닥. 릴레이 GND는 ⑯으로 ESP32 GND(J2-14)에 연결.
   펌프의 큰 전류가 ESP32 GND 선을 지나지 않아 잡음·리셋에 유리. 결과적으로 모든 GND는 공통(SPEC과 동일).
   참고: SPEC §1 문구는 TB2를 "펌프·릴레이 코일 측"이라 적었지만, 이 릴레이 보드는 코일 GND 핀이 따로 없어 **코일 전류는 ⑯ → ESP32 GND → ⑦** 로 돌아갑니다(2.4절). 모두 공통 GND라 동작에는 영향 없음.
4. **다이오드 위치**: 이음부(뚜껑 위) 또는 연장선 박스 쪽 끝 — 전기적으로 동일(4절). 배선도는 이음부, 조립 가이드는 박스 쪽 끝.
5. 릴레이 단자 NO/COM/NC 순서는 보드 실크 기호를 사진으로 판독해 "치수도 방향에서 각 블록 위 = NO, 가운데 = COM, 아래 = NC"로 그림 → **멀티미터로 확인하도록 안내**(COM–NC 도통, COM–NO 무도통).
