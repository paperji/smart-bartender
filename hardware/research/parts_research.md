## 1. 핵심 결론 (먼저 읽기)

1. **배관 규격**: 펌프 출수구는 **외경 7.5mm / 내경 4.9mm** → 보유한 **내경 5mm(외경 7mm) 튜브**가 맞습니다.
   체크밸브(JGB32PPS) 바브는 **끝 Ø3.2 ~ 턱 Ø5.0mm** → **내경 4mm(외경 6mm) 튜브**가 맞습니다.
   두 튜브는 "내경4 튜브 3cm를 체크밸브에 끼우고 → 그 바깥(외경 6mm)에 내경5 튜브를 겹쳐 끼우기 + 케이블타이" 방식으로
   **추가 어댑터 없이** 연결됩니다(1mm 끼워맞춤).
2. **체크밸브가 유량을 크게 줄입니다(추정)**: 내부 유로가 **Ø2.0mm**, 개방압 **2kPa(약 20cm 물기둥)** 라서
   펌프 유량이 **약 3~6 ml/s(추정)** 로 떨어질 수 있습니다(밸브 없으면 약 10~14 ml/s, 추정). 3.3절 참고.
   → 200ml 한 잔에 약 35~65초. SPEC v2.1에서 **펌프당 최대 구동시간이 120초**로 늘어나, 유량이 **2.5 ml/s 이상**이면 한 재료 최대 300ml(`maxStepMl`)까지 가능합니다(4 ml/s면 300ml에 75초).
3. **릴레이(SZH-RLBG-012)**: 채널마다 옵토커플러가 있고, **JD-VCC 점퍼는 2핀(VCC | JD-VCC)** 형이며 **별도 코일 GND 핀이 없습니다**(코일 GND = 메인 헤더 GND).
   SPEC 기본 **A안**(점퍼 제거, VCC=3.3V, JD-VCC=5V)은 널리 쓰이지만 이 보드는 입력이 "표시 LED + 옵토 LED 직렬" 구조로 보여
   **3.3V에서는 입력 전류가 작아(약 0.3~0.7mA, 추정) 안 켜질 수도** 있습니다. 반드시 벤치 테스트 후, 안 되면 SPEC v2.1 공식 대체안 **B안**(**⑪ 3V3 선을 먼저 뽑고 → ⑨ 5V 선을 JD-VCC 핀에서 입력 헤더 VCC 핀으로 옮기고 → 점퍼 캡을 끼움**, VCC = JD-VCC = 5V, IN=GPIO 직결 — 3.2절)으로 전환. 두 안 모두 Active-LOW라 펌웨어는 같습니다.
4. **ESP32 DevKitC V4**: 38핀, 5V 핀 이름은 **"5V"**, **GPIO2 사용자 LED 없음**(5V 전원 LED만) → 상태 LED는 **외부 LED + 220Ω 필수**.
   보드 폭이 넓어 브레드보드 1개로는 불편 → **ESP32-DevKitC 전용 푸시인 터미널 확장보드(P02)** 를 권장.
5. **추가 구매(디바이스마트)** 합계 **79,658원(VAT 포함, 무료배송 기준 66,000원 이상)**.
   여기에 다이소 용기·드립트레이·L자 꺾쇠·자석 캐치, 포맥스 재단비(가격 확인 필요)가 추가됩니다.
6. **용기 폭이 본체 크기를 정합니다**: 기본 본체 **W420은 용기 외곽 폭 ≤ 95mm일 때만** 용기 4개를 한 줄로 넣을 수 있습니다.
   폭 95mm 초과 ~ 120mm 이하면 본체를 **W520**으로(5.4절), 120mm 초과면 다른 용기를 고릅니다. 다이소 1L급 직사각 용기는 대부분 **폭 120mm 이상**이므로 매장에서 자로 실측하세요.
   **용기를 먼저 정한 뒤** 포맥스 재단(5.2절)을 주문합니다.
7. **부저 ONE005는 HIGH=울림** → SPEC v2.1 펌웨어 기본값 `BUZZER_ON_LEVEL 1`과 일치. 상태 LED는 **외부 LED + 220Ω 필수**(4번).
8. **관통 구멍 지름은 조립가이드와 같습니다**(5.6절 일람). 그로밋(P44)은 선반 D **Ø20 ×2** + 뒤판 G **Ø12 ×1**용이고, 5mm 판에 맞는 제품이 없으면 **글루건 마감**으로 대신합니다.
   뒤판 G의 구멍(Ø12·SW1 사각·F1 둥근)은 **STEP4(1주차)에서 미리 뚫습니다** — SW1·F1을 G 바깥에서 끼운 뒤 G 안쪽에서 납땜해야 하므로, 재단된 G판이 STEP4 전에 있어야 합니다.
9. **전장 박스 고정 = 접착식 벨크로(P64, 필수 구매)** 가 기본입니다. 박스 앞쪽 모서리 아래는 사방이 막힌 빈 공간이라 볼트 너트를 끼울 손이 들어가지 않기 때문입니다. 볼트는 선택이며 **뒤쪽 두 모서리(본체 x 약 115·295, y 약 180 — 아래가 용기 칸)** 만, M3×15(P68) + 너트(P38)로 고정합니다(5.6절).
10. **식품용 부품으로 바꾸기 전에는 기기에서 나온 액체를 아무도 마시지 않습니다**(조립가이드 1.3·5장, 시연은 색 물). 시음이 꼭 필요할 때만 **선택(시음 전 교체용)** P65·P66·P67(식품용 튜브·체크밸브)로 바꾸고 펌프 재질을 확인합니다(3.6절). 디바이스마트에는 식품용 표기 제품이 없어 판매처·가격 확인이 필요합니다.

## 3. 호환성 · 설계 판단

### 3.1 펌프 ↔ 튜브 ↔ 체크밸브 ↔ 노즐 (결론: 보유품만으로 연결 가능)

```
[펌프 출수구 외경 7.5]──내경5/외경7 튜브(약 0.7m)──┐
                                                   │ (겹침 이음 1.5cm + 케이블타이)
                         내경4/외경6 튜브 3cm 슬리브 ┘
                                 │
                     [체크밸브 입구 바브 Ø3.2~5.0]  ▶FLOW▶  [출구 바브]
                                 │
                       내경4/외경6 튜브 약 10cm ── 노즐 플레이트 구멍(Ø6.5) ── 잔
```

| 연결부 | 치수 | 판단 |
|---|---|---|
| 펌프 출수구 ↔ 내경5 튜브 | 출수구 외경 7.5 vs 튜브 내경 5 | **꽉 끼움(권장)**. 판매처도 5×8 튜브 장착 사진 제시. 뜨거운 물에 튜브 끝을 10초 담그면 잘 들어감 |
| 펌프 출수구 ↔ 내경4 튜브 | 7.5 vs 4 | 너무 빡빡함(비권장) |
| 체크밸브 바브 ↔ 내경4 튜브 | 바브 턱 Ø5.0 vs 내경 4 | **적합**. 케이블타이로 한 번 조이면 확실 |
| 체크밸브 바브 ↔ 내경5 튜브 | 바브 턱 Ø5.0 vs 내경 5 | 헐거움 → 직접 연결 비권장 |
| 내경5 튜브 ↔ 내경4 튜브(외경 6) | 6 vs 5 (1mm 겹침) | **겹침 이음 가능**. 1.5cm 이상 겹치고 케이블타이 |

- 체크밸브는 **FLOW 화살표가 노즐 쪽**을 향하게, **노즐 바로 앞(선반 아래)** 에 둡니다. 그러면 펌프가 멈춰도 밸브 아래쪽 튜브에 액체가 차 있어(빨대 위를 손가락으로 막은 효과) 다음 제조 때 바로 나옵니다.
- 개방압 2kPa(약 20cm 물기둥)는 사이펀(저절로 흘러나옴)을 한 번 더 막아 주는 안전장치 역할도 합니다. 그래도 **노즐 출구는 모든 용기의 최대 액면보다 높게**(SPEC 1절) 유지합니다.
- 보유 튜브 수량(내경5 8m, 내경4 5m)은 필요량(약 2.8m, 약 0.6m)보다 충분합니다.

### 3.2 릴레이를 ESP32(3.3V)로 구동 (JD-VCC 점퍼)

- 보드 구조(사진 확인): 헤더 `GND IN1 IN2 IN3 IN4 VCC`, 점퍼 `VCC | JD-VCC` **2핀**. 점퍼를 빼면 **VCC = 입력(옵토) 쪽 전원**, **JD-VCC = 릴레이 코일 전원**. 코일 전류는 **메인 헤더 GND** 로 돌아옵니다(별도 GND 핀 없음) → GND 공통 필수(SPEC과 동일).
- 입력 회로는 통상 `VCC → 1kΩ → 표시LED → 옵토LED → INx` 직렬 구조로 알려져 있습니다(포럼 분석 — 이 보드 회로도 원본은 미확인, **확인 필요**). LED 두 개의 전압강하 합이 약 2.6~3.0V라서:

| 방식 | 연결 | OFF(IN=HIGH 3.3V) | ON(IN=LOW 0V) | 판단 |
|---|---|---|---|---|
| **A안 (SPEC 기본)** | 점퍼 제거, VCC←TB3(ESP32 **3V3**), JD-VCC←TB1(**5V**), GND 공통 | 0V 걸림 → **확실히 OFF** | (3.3−2.6~3.0)/1kΩ ≈ **0.3~0.7mA(추정)** → **켜지지 않을 수 있음** | 먼저 시험 |
| **B안 (SPEC v2.1 공식 대체안)** | USB·어댑터를 모두 뺀 뒤 **① ⑪(VCC ← 3V3)을 먼저 뽑음 → ② ⑨(+5V)를 JD-VCC 핀에서 빼서 입력 헤더 VCC 핀(⑪ 자리)에 꽂음 → ③ 점퍼 캡 끼움** → VCC = JD-VCC = **5V**(JD-VCC 핀에는 캡만), IN←ESP32 GPIO 직결, GND 공통 | 5−3.3=1.7V < LED 합 2.6V → **OFF**(추정) | (5−2.6)/1kΩ ≈ **2.4mA** → 확실히 ON | A안 실패 시 |

- **시험 방법(벤치 테스트)**: 브레드보드에서 A안으로 연결 → `{"cmd":"run","p":1,"ms":2000}` 또는 테스트 스케치로 IN1을 LOW → "딸깍" 소리·표시 LED 확인. 4채널 모두 확인. 안 켜지면 B안. 두 안 모두 Active-LOW라 펌웨어는 그대로입니다.
- **주의(B안)**: 점퍼가 끼워진 상태에서 VCC 핀을 ESP32 **3V3(TB3)에 연결하면 절대 안 됩니다**(5V가 3.3V 레일로 역류). B안에서 릴레이 VCC는 **절대 3V3에 연결하지 않음**(SPEC §1).
- **왜 ⑨를 옮기나(B안)**: 점퍼 헤더는 `VCC | JD-VCC` 2핀이고 점퍼 캡이 두 핀을 모두 덮습니다. 듀폰 선이 꽂힌 핀에는 캡이 들어가지 않으므로 ⑨를 JD-VCC 핀에 둔 채로는 캡을 끼울 수 없고, ⑨를 빼고 캡만 끼우면 릴레이에 5V가 전혀 들어가지 않습니다. 그래서 ⑨를 입력 헤더 VCC 핀으로 옮기고, 캡이 VCC → JD-VCC(코일)로 5V를 넘겨줍니다. **⑪을 먼저 뽑는 이유**: 점퍼와 ⑪이 한순간이라도 함께 연결되면 5V가 ESP32 3V3로 거꾸로 들어갑니다. ⑨가 VCC 핀을 차지하면 ⑪을 다시 꽂을 자리도 없어집니다. 옮긴 뒤 전원 없이 멀티미터 도통 모드로 +5V 레일 ↔ VCC 핀, +5V 레일 ↔ JD-VCC 핀이 모두 "삐"인지 확인합니다(조립가이드 STEP2 절차 라와 같은 순서).
- 부팅 중 GPIO가 입력(High-Z) 상태일 때도 두 방식 모두 입력 LED에 전류가 흐를 경로가 없어 릴레이는 OFF 상태를 유지합니다. 펌웨어는 SPEC v2.1 초기화 순서(출력 레지스터를 먼저 HIGH로 `gpio_set_level` → `pinMode(OUTPUT)` → `digitalWrite(HIGH)`; ESP32 코어 3.x는 `pinMode` 전의 `digitalWrite`를 무시)를 따릅니다.
- 참고 자료: RandomNerdTutorials는 "입력이 약 2V 아래로 내려가면 릴레이 동작"이라 설명하고 3.3V/VIN 모두 사용 가능하다고 함([링크](https://randomnerdtutorials.com/esp32-relay-module-ac-web-server/)). 반면 일부 판매처는 3.3V 안정 동작을 위해 입력 저항(1kΩ→220Ω) 교체가 필요할 수 있다고 안내([Phipps Electronics](https://www.phippselectronics.com/support/5v-2-4-8-channel-relay-modules-with-optocoupler-users-guide/)).

### 5.4 폭·깊이 변경 규칙 (용기가 더 클 때)

- **먼저 용기 외곽 폭(w, 좌우 방향, 뚜껑 포함)으로 본체 폭을 고릅니다** (용기 4개 일렬 + 가이드 N 3개):

| 용기 외곽 폭 w | 본체 | 근거 |
|---|---|---|
| **w ≤ 95mm** | **W420 (기본)** | 내부 폭 410 − 가이드 15 = 395 → 칸당 약 98.75 |
| **95 < w ≤ 120mm** | **W520** (ΔW = 100, 아래 규칙) | 내부 폭 510 − 15 = 495 → 칸당 약 123.75 |
| **w > 120mm** | 4개 일렬 불가 → **다른 용기** 고르기 | (가이드·재단표는 W420·W520 두 경우만 계산됨) |

  깊이(앞뒤 방향)가 135mm보다 크면 아래 깊이 규칙도 함께 적용합니다(예: TARK 1L 165×120 → W520 + 깊이 +30). **용기를 정한 뒤에 포맥스를 재단/주문**하세요.
- **폭을 ΔW 만큼 늘릴 때** (예: 폭 120mm 용기 → 본체 W520, ΔW = 100):
  A·C 가로 +ΔW, D·E·F·G·L 가로 +ΔW, H 가로 +ΔW, I 가로 +ΔW/2(각각), 나머지(B·J·K·M·N) 그대로. 잔 칸은 가운데 유지, N 위치는 (내부폭/4) 간격으로 재계산.
  → W520 예: A·C 520×260, D 510×250, E 510×255, F·G 510×115, H 508×253, L 510×15, I 175×255.
  잔 칸·노즐 블록·전장 박스는 가운데(x 260 기준)로 옮기고, 구멍은 판 기준 위치를 그대로 씁니다(D Ø20은 좌·우 끝에서 55, E Ø25는 가로 가운데, F·G는 각 끝에서 같은 거리).
- **깊이를 ΔD 만큼 늘릴 때** (용기 깊이 135mm 초과): A·C·B 깊이 +ΔD, D +ΔD, K +ΔD, N +ΔD (용기 칸만 깊어지고 잔 칸은 그대로).

### 5.5 접착·고정 요령(재료 관점)

- 포맥스(PVC 발포)는 **순간접착제(시아노아크릴레이트)** 로 맞대기 접착이 잘 됩니다(P42). 안쪽 모서리를 글루건(P43)으로 한 번 더 보강.
- 힘이 걸리는 곳(측판-바닥, 상판 탈착부, 선반)은 **L자 꺾쇠 + M3×10 볼트·너트**(P36~P38). 포맥스에 목나사는 잘 빠지므로 관통 볼트+너트 사용.
- 릴레이 모듈은 하이박스 속판에 M3 서포트 10mm(P39) 4개로 띄워 고정(아래쪽 납땜면 단락 방지).
- **전장 박스 → 선반 D**: 접착식 벨크로(P64) 4쌍(박스 바닥 네 모서리와 D의 같은 자리)이 기본입니다. 박스 앞쪽 모서리 아래(x 5~130 / 290~415, y 5~105)는 I·J·E·B·A·D로 사방이 막힌 빈 공간이라 너트를 끼울 수 없고, 조립이 끝난 본체에 구멍을 뚫으면 안 되기 때문입니다. 볼트로 더 단단히 잡고 싶으면 **뒤쪽 두 모서리(x 약 115·295, y 약 180)** 만 쓰고, 너트는 뒤 덮개 H를 열고 용기를 꺼낸 뒤 용기 칸 쪽(D 아래)에서 끼웁니다(M3×15 P68 + P38).
- **상판 C**: 꺾쇠를 B에 달기 전에 각 꺾쇠 가로 다리 아래에 M3 너트를 대고 볼트로 잡은 상태에서 너트 테두리에 순간접착제(P42)를 조금 발라 붙입니다(**캡티브 너트**). 볼트 나사산에 식용유·바셀린을 살짝 묻히면 볼트가 같이 붙지 않습니다. 대안은 자석 캐치(P69, 선택).
